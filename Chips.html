📁 Visual Studio Code — Open Source

The Repository

This repository ("Code - OSS") is where Microsoft develops the Visual Studio Code product together with the community. The source code is available under the standard MIT license.

💻 What is Visual Studio Code?

Visual Studio Code is a distribution of the Code - OSS repository with Microsoft-specific customizations released under a traditional Microsoft product license.

VS Code combines the simplicity of a code editor with tools for editing, building, debugging, and running applications.
